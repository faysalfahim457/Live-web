# WebCollector Studio

Real remote Chromium browser: open a link, browse normally, and every page you visit is collected (HTML, CSS, JS, images, fonts, DOM snapshots) for ZIP download. Temporary storage only. See DEPLOY-BN.md (Bengali) for setup.
